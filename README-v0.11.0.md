# Storm Chaser v0.11.0 — Final Transmission

The approved eighteen-second ending plays automatically after the final tornado lap. The original 910 × 512 edit and soundtrack are converted to Theora/Vorbis for Godot without a new crop, upscale or color grade. The earlier in-engine finale remains a fallback for missing, stopped or stalled video playback.

Pause with P, Escape or controller Start. Resume continues the same movie. Losing application focus pauses it. Skip with Space, Enter or controller A/B/X, or the on-screen button. The final 2,000 data award is issued exactly once, including when skipped or when playback falls back. At least three probes are still required for a completed survey and its hull bonus. An incomplete survey keeps the last checkpoint available for retry.

Completing the tornado lap unlocks THE FINALE on page two of Mateo's Footage. Unlocks survive saves and checkpoint retries. Replays preserve the score, scoreboard, checkpoint and previous screen. The collection now has fifteen movies: six dodge celebrations, eight checkpoint films including the original Ridgeline alternate, and the finale. The gallery return control can be selected with a controller.

The original truck art, smooth restrained fishtail, wheel motion, Mateo in the bed, existing audio, road curves, ninety-degree dirt shortcut, lighter mud, lens splashes, jumps, checkpoints, crash sequence and eight-stage campaign are retained. No Higgsfield, Grok or ElevenLabs generation credits were used for this release.

Portable Windows, Linux and Web exports accompany the Godot source. Start with READ-ME-FIRST.txt in the Windows package for laptop, television and controller setup. No Android or iOS build is included. See VALIDATION-v0.11.0.md for checks and device-testing limits.
