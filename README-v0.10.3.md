# Storm Chaser v0.10.3 — Mud & Drift

The Dirt Shortcut now turns ninety degrees over a tighter arc. Brake briefly on approach, turn right, and release the brake to carry speed through the muddy corner. Rear grip eases into a sustained slide, with a muddy tire fan, audible skid and a lower, slightly wider chase view. Steering and braking keep working throughout; this is gameplay physics rather than a scripted takeover.

The automated driver now brakes for the setup instead of through the entire corner. At higher speed the rear visibly steps out; holding the brake gives a slower, gentler turn. Outward momentum is bounded so steering can bring the truck back. The original orange truck artwork and fixed mesh remain, with smooth heading capped at the existing 0.13 radians and no chassis roll. Mateo stays attached to the bed.

Off-road surfaces are much lighter brown, with damp clay variation, dark wheel ruts, standing water and muddy spray. The asphalt-to-mud boundary now happens as the turn starts, so the shortcut is obvious. Roadside terrain uses smooth texture noise and a stable field grid, and the closed highway spur uses the same wet-asphalt material as the main road.

All eight levels, four supplied checkpoint movies, earned replays, earlier dodge/impact movies, audio, saves and controls remain. No Higgsfield or ElevenLabs credits were used. Calm FX reduces the extra camera movement and spray; steering assist and lighter graphics remain available.

The new 18-second preview is recorded from the exported Linux game. It contains actual driving only. Earlier levels are simulated under normal game rules; the existing checkpoint movie is skipped before recording. This is an offline capture, not a device-performance measurement.

Windows: extract the full ZIP and open Storm-Chaser.exe. Linux: extract and run ./Storm-Chaser.x86_64. Web: serve the whole exported folder over HTTP(S). See README.md for all controls and levels.
