# Storm Chaser v0.12.0 — Heavy Interceptor

The original truck now builds torque, changes gears, compresses and rebounds on landing, and carries recoverable momentum after crooked touchdowns. Engine pitch follows RPM and its body layer follows load. Airborne throttle revs without adding ground thrust. Brief gamepad impact vibration is supported where hardware permits.

The dirt route uses newly generated light clay artwork. Lit rolling fields replace the flat surrounding basin; a new prairie storm panorama adds distant depth. The original truck, Mateo, all eight levels, saved checkpoints, scores and approved movies remain intact.

Download the Windows executable and open it, or extract the Windows ZIP first. Existing saves use the same location. W boosts, S brakes, A/D steers, Space transmits a probe. Brake before crests and use gentle countersteer after a crooked landing. Reduced camera effects and steering recovery remain available.

The preview is actual exported Godot gameplay with audio, using stage selection to show the changed handling. It is not a trailer or a full campaign recording. See the research report for sources and the validation notes for test scope.
